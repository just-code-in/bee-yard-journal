## A Journal in Victorian Naruralist Style for Beeyard Monitoring

### Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key (for the AI Naturalist to rewrite casual yard entries)
3. Run the app:
   `npm run dev`
